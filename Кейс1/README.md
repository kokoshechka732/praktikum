# Кейс 1. Поиск нетипичного поведения заявок на закупку

Задача: в журнале событий по заявкам на закупку найти случаи нетипичного поведения, отделить
нарушения регламента от просто необычных, но допустимых случаев, и обосновать каждую находку данными.

## Данные

`students1.csv` — 12 162 события, 1 000 заявок, 41 пользователь, 22 варианта маршрута.
Выгрузка на 01.07.2026 00:00 (UTC+03:00). Описание полей — в `dataset_description.md`, полный текст
задания — в `task.md`.

## Как считал

События внутри заявки сортируются по `EventIndex`, а не по времени: в одну секунду их бывает
несколько. Длительности считаются по парам `task_created` → `task_completed`, соединённым по `TaskId`
(повторное выполнение этапа создаёт новое задание, поэтому по названию этапа соединять нельзя).

Базовая линия — по когортам «тип заявки × этап»: медиана, p90, p99, максимум, MAD. Основная шкала —
рабочие часы (пн–пт, 09:00–18:00, без праздников и обеда), потому что календарные включают ночи и
выходные, и обычный перенос согласования через выходные даёт 66 «часов». Порог для зависших заданий —
медиана + 10·MAD, а не p99: p99 в когорте, где 4 % заданий и есть аномалии, уже загрязнён ими.

Правила разбиты на два класса. Нарушения регламента (пропуск обязательного этапа, исполнение раньше
утверждения бюджета, этап закрыт не той ролью, самосогласование) порога не требуют. Статистические
отклонения (зависшее задание, повторный этап без основания, зависшая заявка) требуют и всегда идут
с числами когорты.

## Результат

`anomalies.csv` — 66 строк по 56 заявкам: 34 нарушения регламента, 24 статистических отклонения,
8 наблюдений (внеплановая проверка аудитора). Одна заявка может иметь несколько строк.

Крупнейшая группа — 16 заявок, исполненных без согласования руководителем. Ещё 8 заявок исполнены
раньше, чем утверждён бюджет. 8 заданий «Проверки заявки» висели по 198–261 ч при медиане 0,41 раб. ч.
Восемь заявок не завершены 139–161 день.

Что отбросил после проверки (в отчёте есть таблица с числами): «договорная заявка без юрпроверки» —
15 срабатываний, все на заявках, отклонённых до этапа юриста; «аномальная сумма» — 15 выбросов без
бизнес-смысла; «открытая заявка = аномалия»; «возвраты = аномалия»; «события позже среза» — это
дефект выгрузки, а не поведение процесса.

## Запуск

```bash
python analysis.py
```

Внешние пакеты не нужны. Скрипт читает `students1.csv` из текущей папки, пишет `anomalies.csv` и
таблицы в `out/`. `out/candidates.csv` — те же строки с номером сработавшего правила и приоритетом.
