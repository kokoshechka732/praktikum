# Кейс 3. Продуктовые гипотезы по данным подписочного VPN-сервиса

Задача: по дампу серверной БД и логам клиентов сгенерировать продуктовые гипотезы и подтвердить
каждую числами. Гипотеза оценивается отдельно, поэтому в отчёте их пять, и каждая оформлена
одинаково: утверждение, метрика, число, контрольная группа, ограничение.

## Данные

Публичная выгрузка (43 файла, около 10 ГБ): CSV-дамп PostgreSQL с разделителем `;` и без заголовков,
клиентские логи, история рекламы и подключений. В репозиторий не входит, скачивается скриптом:

```bash
python download_data.py     # качает в data/, умеет докачивать
```

Готовые результаты расчётов лежат в `out/`, так что отчёт можно читать без выгрузки.

## Что важно знать про данные

Половина выводов зависит от качества дампа, поэтому дефекты вынесены в начало отчёта:

- `orders` покрывает фактически только март–август 2026, поэтому покупку считаю по `subscribe`;
- `transactions` в 7 раз больше `orders` — это попытки платежа и рекуррентные списания;
- `device_identifier` — build-тег Android, а не идентификатор устройства: наивная склейка по нему
  даёт 671 тыс. ложных объединений пользователей;
- объёма трафика в байтах нет, таблица лимитов `sub_limit` не выгружена — лимиты проверяются только
  прокси-метриками;
- `user_blocks` покрывает только ноябрь 2024 – июнь 2025 и содержит rate limit, а не лимит трафика.

## Результат

1. **Мультиаккаунты ради триала.** Граф тождества по отпечатку карты и UUID устройства даёт 1 045
   кластеров, в них 518 триалов — 2,3 % всех триалов. Это нижняя оценка: с IP и User-Agent выходит
   38,2 %, но NAT даёт ложные склейки. Крупнейший кластер — 7 аккаунтов, 7 триалов, 0 оплат.
2. **Лимиты бесплатного тарифа.** Платный пользователь подключается в среднем 4,05 раза в день
   против 2,52 у бесплатного, 47,9 % бесплатных дней — одно подключение. Поведение согласуется с
   «упёрся в лимит», но оптимальный объём в мегабайтах из этих данных не выводится.
3. **Сколько ждут до покупки.** С триалом покупают 40,6 %, без триала 0,26 %; при этом 77 % оплат
   приходят позже 30 дней после старта триала, а 46,4 % платящих триал вообще не использовали.
4. **Ошибки оплаты.** В основном это брошенная корзина: одна неудачная попытка не повторяется, а
   медиана до `failed` — 62 минуты, то есть время жизни платёжной сессии. Доля неудач упала с 39,8 %
   в марте до 15,6 % в июне 2026.
5. **Рефералы.** Конверсия 17,6 % против 0,80 % у органики, в 22 раза, но выборка маленькая (581
   человек), так что это повод тестировать канал, а не доказанный эффект.

## Запуск

```bash
python download_data.py     # один раз, около 10 ГБ
python case3_analysis.py    # все пять гипотез, пишет out/
python h1_sensitivity.py    # границы оценки мультиаккаунтов
```

Нужны `duckdb`, `pandas`, `pyarrow`. Скрипты читают `data/` из текущей папки.

## Файлы

| Файл | Что это |

| `case3_analysis.py` | все расчёты по гипотезам |
